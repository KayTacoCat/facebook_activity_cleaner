# Install (No coding required)

## If you downloaded from **Releases**
1. Download `facebook-activity-cleaner-extension.zip` from the latest release.
2. Unzip the file.
3. Open Chrome.
4. Visit `chrome://extensions`.
5. Turn on **Developer mode** (top-right).
6. Click **Load unpacked**.
7. Choose the unzipped `facebook-activity-cleaner-extension` folder (the one that directly contains `manifest.json`).

## If you downloaded from **Code → Download ZIP** on GitHub
1. Unzip the repo ZIP (for example: `facebook_activity_cleaner-main`).
2. Open Chrome and visit `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select this exact folder inside the unzipped repo:
   `facebook_activity_cleaner-main/release/facebook-activity-cleaner-extension`

## Fix for "Manifest file is missing or unreadable"
You selected the wrong folder. Select the folder that directly contains:
- `manifest.json`
- `background.js`
- `contentScript.js`
- `sidepanel.html`

You're ready to use the extension.
