# Facebook Activity Cleaner Extension

## Install (normal users)
1. Download the latest release ZIP.
2. Unzip it.
3. Open Chrome.
4. Go to `chrome://extensions`.
5. Turn **Developer mode** ON.
6. Click **Load unpacked**.
7. Select the unzipped `facebook-activity-cleaner-extension` folder.

## Notes
- This extension is for personal-use review/cleanup support in your own Facebook Activity Log.
- Default mode is preview/dry-run.
